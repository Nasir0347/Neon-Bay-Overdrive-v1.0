# Nasir — Bazaar Stories: implementation tracker

Scope: improve the existing Three.js/Capacitor game; five unique story missions. No Unity installation. Preserve the named shops and original models. Default to relaxed, welcoming play with optional normal challenge.

## Research decisions

- Teach one action at a time; clear objectives, interactive tutorial, readable text, adjustable challenge. [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/full-list/), [Xbox objective/tutorial guidance](https://learn.microsoft.com/en-us/gaming/accessibility/xag-version-history).
- Share/merge repeated geometry and reduce draw calls before adding detail. [Three.js guidance](https://threejs.org/manual/pages/optimize-lots-of-objects.html).
- 30 FPS is a target, not a device result; measure actual frame times and thermals before claiming performance. [Android performance workflow](https://developer.android.com/games/optimize/gameperformance).

## Acceptance

All five missions complete in order through their distinct objective rules. Merely visiting a delivery marker cannot finish a handover. Wrong vehicle/missing parts cannot advance. Rewards cannot be duplicated. Retry resets timing and restores a useful safe position without losing valid progression. Continue restores the active objective. Replay never reduces campaign progress. Pause/background/mode switches clear held inputs. Default mode avoids forced deadlines and harsh penalties. Help is available at any time. Final APK matches tested runtime files.
